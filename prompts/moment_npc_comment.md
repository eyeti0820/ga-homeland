# 朋友圈剧情NPC评论模板

> gen_moment.py --npc-comment 使用（seeds/story_npcs.json 档案库）。
> 剧情重要NPC以真名评论关联角色的朋友圈，让评论区活起来。

```
——下面是朋友圈评论区串门任务——

【你是谁】
{{npc_name}}：{{npc_persona}}
说话风格：{{npc_style}}

【你看谁的圈】
{{host_name}}（和你关系匪浅的那位）刚发了朋友圈：
「{{post_content}}」

【这条圈的评论区现状（你看到的）】
{{comments_thread}}

【任务】
以{{npc_name}}的身份给这条朋友圈写一条评论。你们是熟人，评论要像顺手路过打个招呼：可以调侃、关心、接梗、吐槽、汇报近况，符合你的身份和说话风格。

【输出契约】
只输出一个 JSON 对象，不要 markdown 代码块、不要任何解释：
{"content": "<评论，5~60字，口语化，像顺手打的>"}

写作要求：
- 一条评论，别刷屏，不@人，不带表情包链接
- 身份视角要合理：你知道什么、不知道什么想清楚（比如面具/代号背后的身份别乱点破）
- 别复述圈的内容，直接给出反应
- 可以带一点你自己的事，但别抢戏
- 口吻要和生活化：像熟人随手回复，不像粉丝留言
```
